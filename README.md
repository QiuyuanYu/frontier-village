# 边境小镇 · Frontier Village

一个基于 HTML5 Canvas 的轻量级边境村庄经营小游戏。  
你可以建造农田、伐木场、酒馆、兵营等建筑，招募村民，进行贸易，训练民兵抵御强盗，最终将荒地发展为繁荣的村庄。

## 🎮 玩法

- **建造**：在地图绿色空地上建造各类建筑，每个建筑都有独特产出。
- **村民**：招募村民并自动分配工作，人口受住房容量限制。
- **贸易**：出售资源换取金币，或购买紧缺物资。
- **防御**：训练民兵和守卫，抵御随机袭击。
- **任务**：完成左侧任务列表中的目标，领取奖励。
- **胜利条件**：村庄发展到 5 级即可通关。

游戏进度会自动保存在浏览器本地，刷新页面不会丢失。

## 🚀 在线游玩

部署到 GitHub Pages 后，访问：  
`https://你的用户名.github.io/frontier-village/`

## 🛠️ 本地运行

直接双击 `index.html` 即可在浏览器中打开游玩。
